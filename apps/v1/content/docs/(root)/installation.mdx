This guide provides the essentials for adding Marval UI components to your React application.

## Prerequsites

Our components are built with Tailwindcss, Motion, Radix UI. 

<Steps>
<Step>Typescript</Step>



This project and the components are written in TypeScript. We recommend using TypeScript for your project.

<Step>Motion</Step>

Marval UI ships smooth, production-grade animated UI components with Motion library.

```bash showHeader
npm install motion
```

<Step>Install [Tailwind CSS v4](https://tailwindcss.com/docs/installation/using-vite)</Step>

If your project is React, Vite, or Tanstack.

```bash showHeader
npm install tailwindcss @tailwindcss/vite
```

```js showHeader filepath="vite.config.ts"
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    tailwindcss(),
    ...
  ]
})
```

Or if your project uses Next.js.

```bash showHeader
npm install tailwindcss @tailwindcss/postcss postcss
```

```js showHeader filepath="postcss.config.mjs"
const config = {
  plugins: {
    "@tailwindcss/postcss": {},
  },
}
```

Finally, add Tailwind CSS import

```css showHeader filepath="globals.css"
@import "tailwindcss"
```

<Step>Install Radix UI</Step>

Our base components rely on Radix UI.

```bash showHeader
npm install radix-ui
```

The `radix-ui` is tree-shakable, that is, the final bundle will include only the components you import.

<Step>Install `cn()` utility</Step>

```bash showHeader
npm install clsx tailwind-merge
```

```ts showHeader filepath="src/lib/utils.ts" 
import { type ClassValue, clsx } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
	return twMerge(clsx(inputs))
}
```

</Steps>

## Working with LLMs

We structure the documentation to make the components AI-friendly, so language models can understand, reason about, and modify them. To support this, we include:

- A llms.txt, a documentation map for your AI agent.
