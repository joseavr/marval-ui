Marval UI is a modern, accessible component library designed to help developers build beautiful user interfaces with ease. Built as a monorepo using **Turborepo** and **pnpm**, it leverages the latest web technologies to deliver a seamless development experience.

## Why Marval UI?

Marval UI combines best-in-class tools and libraries to provide:

- **Accessibility First**: Built on Radix UI primitives, every component comes with WAI-ARIA compliance out of the box.
- **TypeScript Support**: Fully typed APIs for a seamless development experience with intelligent autocomplete and type safety.
- **Modern Styling**: Powered by Tailwind CSS v4 for utility-first styling that's both flexible and performant.
- **Beautiful Animations**: Integrated with Motion (formerly Framer Motion) for smooth, declarative animations.
- **Developer Experience**: Built on Next.js 16 and React 19, taking advantage of the latest features and optimizations.

## Open Source

Marval UI is open source and freely available for both personal and commercial projects. We believe in building tools that empower developers to create exceptional user experiences without reinventing the wheel.
