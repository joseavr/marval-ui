## Installation

The Button component is part of the JoseUI component library. You can add it to your project using the CLI:

```bash showHeader filepath="src/index.js" showLineNumbers
pnpm dlx @joseui/cli add button
```

## Props API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | `"default"` | The visual style variant of the button |
| `size` | `"default" \| "sm" \| "lg" \| "icon"` | `"default"` | The size of the button |
| `className` | `string` | - | Additional CSS classes to apply |
| `disabled` | `boolean` | `false` | Whether the button is disabled |
| `asChild` | `boolean` | `false` | Render as a child component (for composition) |

All standard HTML button attributes are also supported.
